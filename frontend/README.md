# StudyQuip Web UI

基于 React、TypeScript 和 Vite 的单用户工作台。作者 Null，邮箱 pylindex@qq.com，采用 MIT 许可。

## 本地开发

在项目根目录按主 README 初始化并启动后端和 worker，然后执行：

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

开发服务器默认绑定 `127.0.0.1:5173`。`/api` 由 Vite 同源代理到 `http://127.0.0.1:8765`，可用 `VITE_API_TARGET` 修改目标。后端的 `STUDYQUIP_ALLOWED_ORIGINS` 需要包含实际访问的开发地址。局域网开发时显式执行 `pnpm dev --host 0.0.0.0`，并配置对应 Origin；生产使用后端直接提供 `dist`。

```sh
pnpm format:check
pnpm test
pnpm build
```

安装构建脚本仅显式允许 esbuild；依赖版本由 pnpm-lock.yaml 固定。

## 实现边界

- 模型按教材图片、教材文本、题目图片、题目文本、向量嵌入、语音识别和语音合成七种用途独立编辑。`roleLabels/roleDescriptions` 统一列表标签、用途选项和职责说明；四种生成用途都支持 Chat Completions／Responses。首页检查题目图片及文本配置，教材模型可单独配置。
- 旧视觉／讲解记录由后端在启动时自动复制到两个对应的新用途，前端只读取转换结果；地址、Key 与参数继承，之后修改或删除互不覆盖。升级本功能后需完整重启 Web／worker 并刷新浏览器，随后普通模型参数修改仍按热重载生效。
- “上下文预算”默认留空，清空后以 `null` 保存；应用的完整请求、教材材料和正文读取均不再采用隐含长度上限，概述和嵌入分批也不回退到默认预算。填写时才按显式预算组织材料并检查完整工具上下文。此字段不会发送给服务商，也不会取消服务商自身限制。
- 任务页与教材详情共用 `ResumeJobButton`，根据服务端 `resume` 投影显示“继续处理”；尚无保存结果时显示“重新执行”。弹窗说明保留进度，提交 `/jobs/{id}/resume` 并携带预约配置；刷新后仍使用同一任务，不能因失败而把已有教材当作全新任务。不可续接的原因在进度区显示，完整模型上下文不发给前端。
- “最大输出”默认留空，清空后以 `null` 保存；两种 API 都完全省略对应的输出上限参数，填写正整数时才发送。留空时使用服务商默认上限，输出长度字段选择暂不可用。
- 所有业务数据来自 `/api`，前端没有演示数据。修改请求带会话 CSRF token；模型测试、识别、讲解、语义检索和导出均提交持久任务。
- 工作台通过 `JobsProvider` 共用一份任务状态，每 3 秒更新，写操作与窗口重新聚焦时立即刷新；切换页面保留状态，重载页面从数据库恢复。状态尚未取得或接口失败时暂停处理入口，服务端仍负责最终去重。旧请求被取消，避免迟到响应覆盖新状态。
- 教材列表显示阶段与页数，详情区分识别、正式整理、校对、跳过、概述和向量索引；任务详情显示模型、配置版本、当前原页、请求等待、执行次数、用量及最近活动。`#tasks?job=<id>` 定位并突出相应任务。进度是已提交成果与请求状态，不估算整本教材的剩余时间；心跳不等于内容有新进展。
- 教材识别成功后直接进入草稿，不按模型质量标签拦截。新版 worker 启动时将旧待校对页恢复为草稿，识别进度随数据库状态更新；有人工修改则保留，否则使用已存 AI 草稿。手工校正、重新识别、跳过仍可使用；人工保护内容的建议审阅与题目答案确认继续保留。
- 错题生成、页重新识别、模型测试、检索与 PDF 导出复用未结束任务。检索的查询和结果可在刷新后恢复；自动刷新不会覆盖正在编辑的页草稿，草稿仍用开始编辑时的版本保存，版本冲突需人工核对。
- 模型表单保存后，后续独立处理单元和点击“继续处理”后的未完成单元读取新配置；已完成内容不会因改模型重新生成。已经发出的请求及同一工具调用链继续使用旧模型与协议。并发、窗口、超时和重试按后续请求刷新，应用级 `.env` 配置不在此范围。详细边界见根目录 `docs/ai-runtime.md`。
- 教材和题目的四种生成用途均支持显式选择工具策略：强制调用（默认）、由模型选择、不发送，适用于 Chat Completions 和 Responses。DeepSeek 思考模式需选择不发送；不会按服务商名称自动调整配置，应用仍校验工具返回结构。
- 模型高级参数的“自动重试次数”复用 `retries` 字段，网络与格式错误分别计数，默认 2、0 为关闭。任务详情显示“格式重试 当前次数/额度”，等待时附校验原因；次数耗尽后仍可通过已有“继续处理”入口续接当前单元，不从头重跑。
- 页面按需加载；普通界面使用设备系统字体，PDF 使用随应用分发的 Noto 中文字体。外观使用图标三段式单选控件，支持浅色、深色和跟随系统，保留键盘方向键切换与清晰的选中、焦点状态；偏好保存到当前浏览器，跟随系统时即时响应系统外观变化。
- 默认首页展示真实的最近错题、教材和待处理任务；空资料库根据实际配置显示开始步骤。首页提供录入、导入及打开已有记录的快捷入口，有活动任务时在可见页面刷新状态。主导航在手机上改为顶部图标与文字布局。
- 品牌图标为原创书页与 Q 组合，登录、侧栏和 favicon 共用 `public/studyquip-mark.svg`；导航及相关操作使用按需导入的 Lucide 图标。教材提示采用独立的琥珀色主题变量，与灰绿色主操作区分，并提供导入入口。
- 相册/文件与拍照为独立入口。拍照使用 `input capture="environment"`，由移动系统相机处理；桌面或不支持 capture 的浏览器显示文件选择器。无需网页摄像头权限或 getUserMedia。
- 图片裁剪根据经过 EXIF 归正的预览图自然尺寸提交坐标；PDF 原件与文本文件没有裁剪按钮。UUID 使用标准库，并兼容局域网 HTTP 上没有 `crypto.randomUUID` 的浏览器。
- 教材目录使用任意深度父子树；段落修改使用 revision 和操作组 ID，网络失败后相同内容重试沿用组 ID。历史恢复创建新修订，涉及合并或拆分的历史不可强制单段恢复。
- 题目预览与 PDF 共用 Markdown/KaTeX 渲染，不执行原始 HTML，不加载 Markdown 远程图片。题目原图、参考答案图和备注不直接混入打印正文。
- “AI 整理题目”同时规范题干与选项的公式，使用现有预约和任务入口。编辑器说明保留题意地优化表述和公式，显示服务端 `formatting_warnings`，含义不明时保留已有原文；编辑和预览模式都展示核对提示。内容变化后答案需重新确认，旧讲解过期；手动修改题干或选项清除旧提示。旧记录没有此字段时不显示提示，打印正文不包含核对提示。
- “做错原因”由用户填写，可留空，与原错误作答和备注分别保存。“让 AI 优化表述”默认不勾选；勾选且原文非空时，在生成讲解的同一次模型调用中优化表达，原文始终保留。优化结果单独标注，取消勾选、清空原文或修改题目使讲解过期后立即隐藏，重新生成后显示新结果。错题搜索包含原文。
- `/print/:id?token=…` 仅加载授权导出快照。只有中文普通/粗体字体、公式和全部配图通过校验，才设置 `window.__STUDYQUIP_PRINT_READY__`；失败设置 `window.__STUDYQUIP_PRINT_ERROR__`。练习模式在渲染边界再次关闭答案、解析和知识点。
- PDF 将题号、题干、必要配图、选项和作答留白作为分页单元；短题尽量保持完整，解析仍可在段落间自然跨页。

单元测试覆盖答案选项映射、做错原因的默认选择与优化结果显示边界、导出内容隔离、练习模式保护、数学/化学公式，以及首页最近记录排序与待处理状态判断。根目录的本地验收脚本覆盖真实 Web/worker、登录、首页入口、PDF 与移动视口，并在独立空资料库视图验证外观单选、键盘切换、刷新持久化及系统跟随；不依赖真实上游模型来伪造 AI 验收结果。

不允许启动应用进程时，可在构建后从根目录运行 `uv run python scripts/verify_task_ui.py`：该脚本只启动 Chromium，通过本地路由夹具验证任务状态恢复、防重复按钮、失租／接口失败提示、未保存草稿保护、检索恢复和移动布局，并检查七种模型用途的列表、选项及职责说明。它不能替代真实后端端到端或实体手机验收。


新增题目编辑器复用根题目状态，以 QuestionNavigator 的目录选择／父级返回／子题入口切换当前节点；只显示当前节点表单，避免深层无限缩进。增删、同级调整顺序和多层大题共用 `changeAt/atPath`；整题统一保存、确认和调度，材料编辑和插图编辑组件独立复用。听力素材位于材料中，支持音频上传与播放、文稿和缺失模型提示，保存后通过服务端待处理投影安排补全；AI 合成录音有标记。

设置用“模型连接／科目管理”分栏，模型按题目／教材／检索／听力用途过滤，未配用途提供入口。流式默认打开、可关闭并单独控制 Chat 用量请求；音频用途显示对应语言／音色／语速表单。科目重命名提交原 ID 与 revision。检索默认单一关键词，支持切换向量或手动添加第二种并调整顺序；可筛书、清空选择，选单书时浏览实际目录路径并限定子树。结果标题显示实际提交的查询，避免输入框变化后误认结果来源。

`Figures.tsx` 提供共用 SVG/坐标图；函数经过 AST 白名单后编译，非有限值与不连续区段断开，禁用赋值与对象访问。坐标图和 SVG 渲染失败标记 `data-figure-error`，Print 拒绝缺图成功；图形编辑有预览。练习版短题尽量不拆页，选择题横向紧凑排列，仅简答留空；复习版展示原作答、原错因、可选 AI 优化表述、详细讲解和教材依据。

不启动后端的完整 UI/PDF 夹具：`uv run --locked python scripts/verify_question_ui.py`（先 pnpm build）。用真实 Chromium 验证嵌套编辑、音频上传表单、科目重命名、流式开关、目录范围，生成中文/公式/图片/SVG/坐标图练习及复习 PDF，并强制字体失败确认拒绝导出。仅调用本地路由夹具，不接触业务数据库或真实模型；不替代实体手机和实际语音模型质量验收。


`SearchPanel.tsx` 是教材、题目检索和打印选题的共用入口。题目部分与条数上限读取 `/search/options`；部分可多选，科目／题型同时限定。教材可选书和任意目录子树。关键词匹配支持任意词、全部词、连续原文。默认只有一种方式，添加／移除／交换后将偏好保存在当前浏览器；无隐式双路检索或分数融合。结果按 method 分段标记，题目命中显示具体部分和子题路径。

`QuestionExport.tsx` 提取既有导出对话框，顶部可展开“检索相关题并加入打印”，共用 SearchPanel 并强制 `confirmed_only=true`。加入时重新读取当前题目，去重并允许排序、移除；最终仍由导出 API 完整校验答案确认和讲解新鲜度。搜索与打印使用各自 context 恢复任务，刷新不会丢失正在执行的检索状态。索引进度复用 JobProgress，不阻挡题目表单编辑。

浏览器路由夹具新增验证单方式默认、双方式顺序／删除、题目部分／题型与每种条数提交、检索命中加入打印和去重、手机视口无溢出。实际生成的 PDF 继续使用既有题目内容组件与字体就绪协议。
