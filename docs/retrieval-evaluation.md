# 检索通道最小对照记录

运行命令：`uv run python scripts/evaluate_retrieval.py`。脚本只创建临时数据库，使用六段自建中文示例、三条人工标注查询和可复现的二维向量，不读写实际教材、不调用模型。每条查询取前两个正文块，三组实验使用同一份 FTS、向量、正文及权重，仅关闭或开启目录与关系通道。

| 查询场景 | 基础混合：命中／相关，噪声 | 加目录：命中／相关，噪声 | 加目录及关系：命中／相关，噪声 |
| --- | --- | --- | --- |
| 自由落体，正文直接命中 | 1／1，1 | 1／1，1 | 1／1，1 |
| 行星轨道，目录概述路由 | 0／1，2 | 1／1，1 | 1／1，1 |
| 惯性，需要质量单位的相关内容 | 1／2，1 | 1／2，1 | 2／2，0 |
| 合计 | 2／4，4 | 3／4，3 | 4／4，2 |

“噪声”指此次标注中不属于相关答案依据的返回块。三个变体各返回六块，并不是六块均正确。目录样本有意包含正文未直接出现的“行星轨道”概述；关系样本有明确原文“惯性大小以质量衡量”，通过服务端引文校验后才建立关系。

该对照发现并修复了两个执行问题：已经在向量候选中的关系目标原先未能再次参与关系通道评分；全部弱向量候选作为关系起点会给无关概念加权。目前优先以直接关键词和目录命中作为关系起点，两者均无命中时才用有限向量候选；同一通道去重，但允许不同通道为同一正文提供排序证据。必要近邻仅补充同目录的插图或未完整结束的正文，不对所有候选的相邻段落无条件加权。

本结果说明通道连接和作用可复现，**不能证明真实教材上的总体准确率提升**。向量是人工构造的，目录概述和关系也是已知示例；实际视觉识别、概述质量、真实嵌入模型和关系抽取噪声仍需要真实教材与已确认答案做验收。此次外部模型请求为零，不能据此推算真实导入费用。
