# 教材修订与检索协议

本协议对应 `textbook.py`、`lexical.py`、`context.py` 和 `retrieval.py`。源文件、页草稿与正式内容分离；只有正式内容执行 NFC。坐标使用正式版本的 Unicode 码点区间 `[start,end)`，不能直接使用 JavaScript UTF-16 索引。

## 正式内容与目录

目录是任意深度树，节点可以同时拥有正文和子节点。节点字段为 `id/book_id/parent_id/title/order/revision`；每本教材有稳定根节点。正文块使用 `id/book_id/node_id/text/type/order/source_page_ids/asset_ids/revision/human_protected/archived`。显示引用时使用书名与实际目录路径，页序只用于内部校对。

所有变更经过 `TextbookService.apply_operations`。参数 `group_id` 标识一次提交，`operations` 支持：

- `insert`：`id` 可由调用方提供；`block` 包含 `text`、可选 `node_id/type/order/source_page_ids/asset_ids`。
- `update`：`id/base_revision/changes`；支持 `text_edit:{start,end,expected_text,replacement}` 的精确局部修改。
- `move`：`id/base_revision/node_id/order`。
- `split`：`id/base_revision/parts`，其中 `parts` 是完整分割后文本数组。
- `merge`：`ids/base_revisions`，可选合并后 `text`，缺省按原順序以空行连接。
- `archive`：`id/base_revision`。
- `node`：`node:{id?,parent_id,title,order?,base_revision?}`。

已有对象必须提供基础版本。整个操作组先在内存模拟，再在 SQLite savepoint 内提交；任何业务拒绝回滚该组，拒绝回执保存于外层事务。worker 在同一外层事务中校验租约并提交检查点。数据库锁超时或崩溃导致外层事务回滚时，不留下假终态。

操作组成功或业务拒绝后 ID 即耗尽。相同 ID、相同载荷返回原回执；不同载荷返回 `idempotency_conflict`。修正版必须使用新 ID。回执与该教材共存，不随任务重试清除。

## 人工保护、重定向和证据

人工修改自动受保护。AI 触及受保护块或目录时形成建议，新的目录节点及正文插入部分先独立保存，再把修改已有内容、合并等剩余操作交给审阅。建议记录前后版本、理由和基础版本；采纳重新检查版本，过期转为 `stale`。忽略相同提案与基础版本后，不重复制造建议。

合并保留当前文档顺序最前 ID；当前重定向表扁平化到最终存活块，没有查询递归。拆分保留首块 ID。旧版本到新块的区间迁移独立记录。FTS 在同一事务重建对应当前块，旧向量失效。概念、关系和当前引用投影的证据必须重新定位并验证；不能验证则标记 `migration_unverifiable`。历史讲解快照不被重定向改写。

引文基础规范化固定为 NFC、连续 `str.isspace()` 空白折叠为一个普通空格、去除首尾空白。标点、全半角和 OCR 替字不自动等价，数学符号不被 NFKC 改写。库侧空白折叠保留回到正式文本的坐标映射。

引文必须带块 ID、版本、原句，重复出现时还需 `span_hint` 消歧。硬拒绝原因分别为：`empty_quote`、`normalized_quote_mismatch`、`ambiguous_quote`、`span_out_of_bounds`、`span_hint_mismatch`、`stale_source_revision`、`source_out_of_scope`。近似检索只能辅助找原文，不能成为证据校验的捷径。关系无证据或者达到数量上限时写入拒绝记录，不建立活动边。 非结构关系数量按当前有效关系统计：每块默认 3 条、每概念默认 6 条、每目录节点默认 12 条，均合并计算 source 与 target 两端，入边不能绕过上限；更新同一关系不重复占位。上限由 Settings 集中配置。

## 长书上下文

每页先形成草稿，正式修订顺序执行。`ContextBuilder.build` 装配书名、当前目录祖先、有限相关目录、当前页处理单元、前两页最新块、可选后一页草稿、工作记忆和建议句柄。此前页面跳过会形成缺口，不跨缺口拼句。

教材图片／PDF 草稿使用 `book_vision`；顺序修订、目录概述及建议重新生成使用 `book_text`。这两份配置与题目用途独立，旧视觉／讲解配置在启动时自动拆分继承；嵌入仍共用 `embedding`。详见 [模型用途与兼容转换](ai-runtime.md#模型协议)。

草稿识别不设独立的每书页数并发限制，直接通过共享模型／凭据并发管理器申请请求名额。识别完成顺序不改变原始页序；后续正式修订按输入顺序逐页处理，取消教材任务时一并取消尚未结束的草稿识别协程。

教材工作台分别呈现原页识别与正式整理的已提交页数，待校对／跳过页另列；目录概述和向量索引在后续阶段独立计数。进度持久化不依赖当前浏览器，重载不再创建第二个同书整理任务。原页草稿后台更新时保留正在编辑的文本及其基础版本，防止刷新覆盖人工输入。

识别结果只包含正文和空白页标记，不再分 `good/uncertain/unusable`，不因页尾未完句等质量判断补救识别或暂停。成功结果直接保存为草稿，用户仍可重新识别、手工校正、跳过及显式选择 PDF 纯文字降级；格式错误与网络错误沿用工具协议。

新版 worker 启动时将未删除教材的旧待校对页自动转为草稿；`human_edited` 为真则保留人工文字，否则优先采用 `recognition_draft`，没有候选时保留 `text`。空字符串候选也合法；原件、历史与已完成正文保留。转换逐页短事务、可重复执行、不调用模型。仅旧页面质量导致的人工等待会重新排队，其他失败或取消任务需点击继续。

失败、取消或等待人工处理的教材可从任务页和教材详情“继续处理”。沿用原任务和操作回执；已识别页复用，已完成页和单元跳过，相同配置下的未完成工具链携带完整思考项及工具结果续接。每个新阶段保存初始输入快照；`revision_plans[page_id:revision]` 中的旧 `context_budget` 不再施加上限，材料总预算由最新模型配置决定。已存 `unit_budget` 仅固定分段边界，`null` 代表整页单元，防止修改配置后重复提交正文；未开始的新页留空时不按长度拆分。旧检查点缺少新增字段时补建，不要求架构迁移或删除内容。

每页修订和每次独立结构化调用读取最新模型配置。当前工具链内固定协议、模型与生成参数；点击继续后，在新的执行尝试开始时也重新读取配置。配置或工具结构改变时只重建未完成单元，保留原页、正式块、操作回执、用量及已完成单元。嵌入空间改变在批次边界重新规划，不把已生成的旧向量重标为新空间。详见 [热重载协议](ai-runtime.md#模型配置热重载)。

模型结果中的数组允许单键 `item` 包装或标准 JSON 数组字符串的明确解码，元素类型与业务约束仍完整校验。继续旧格式失败任务时，若配置兼容且最后一次独立提交能通过当前校验，复用保存的结果进入操作组提交，不再生成同一页；保留原始参数、错误反馈和用量。必需操作含额外键、缺失字段或其他无法明确转换时继续走模型重试，不能靠丢弃正文操作通过校验；可选增强项按下述隔离协议记录拒绝。

只有显式填写模型上下文预算时，才用 UTF-8 字节数作保守上界控制材料长度，工具定义与估算字段均计入预算。先丢弃整份可选后一页、无关目录和较远近邻原文，保留可按 ID 读取的句柄；不截断当前修改目标。超长页通过 `units()` 无损拆分，所有单元拼接严格恢复输入。`current_page.unit_index/unit_count` 让执行层在最后单元完成前不把整页标为完成。

模型“上下文预算”留空时，`ContextBuilder(db, token_budget=None)` 不按 token 拆页、缩减目录／近邻／工作记忆，亦不拒绝完整工具请求；移除全局默认 24000 和 `STUDYQUIP_CONTEXT_TOKENS` 回退。仍按原页、相关前后文和开放结构组织，不主动携带整本前文。显式填写上限时才检查材料与完整请求，超限不裁剪思考或未完成协议项。

远处块通过 `read_block` 获取最新版本，可指定码点范围；只有设置显式预算后，单次读取过长才拒绝并要求缩小范围。摘要不能替代目标原文。`node_source_fingerprint` 基于直属内容版本、子节点概述来源和当前标题，修改后按受影响祖先标记过期。概述分段缓存另包含实际段落文本指纹，避免取消预算后复用旧首段作为整节点概述。

新修订单元明确区分 `current_page.id`（原页来源）、目录 ID 和已有正文块 ID。草稿已在 `current_page.text`；`previous_blocks` 是本轮服务端已读取的最新版本，可直接用于跨页续接，不要求再调用工具确认一次。仅提供正文、类型、ID、归属、顺序、版本、来源和人工保护字段，省略无关存储元信息。远处或被省略的正文仍须读取，不能用摘要代替。`library` 明确正式块和目录节点数量；还没有正式块时移除搜索与块读取工具，目录已全部给出时仅保留结果提交工具。

正文整理优先。提示词及工具定义明确概念／关系可返回空列表；封面、版权和目录保留原文及真实目录，不为出版社、奖项或装饰生成学科关系，不为凑齐增强字段追加检索。必需正文操作整体校验；可选概念／关系逐条解析，错误提案与原因写入 `relation_rejection`，格式拒绝记录附原页及操作组 ID。有效增强项仍执行全部证据和范围校验；正文、拒绝记录与进度在同一短事务中提交。拒绝某条关系不会回滚本已合法的正文，也不会触发整页重做。人工保护、版本冲突和证据硬校验继续生效。

## 独立检索与重建

FTS 统一使用 jieba 不启用 HMM 的搜索分词，包含标题、目录路径、正文、概念名称和别名。ANY 使用搜索词 OR；ALL 使用非重叠分词 AND；所有字面量转义，用户不能直接注入 FTS 运算符。短语采用规范化全文的连续匹配。空查询返回空。词法指纹包含 Unicode、jieba、词典内容、规范化版本和大小写规则，指纹变化要求重建。

教材只为活动正文块生成查询所需向量，停止生成原排序通道使用的目录概述向量；旧目录向量保留但不参与当前查询。目录概述仍可通过独立浏览工具读取。向量存放普通 BLOB 表，空间指纹不含凭据，包含端点、模型修订、维度、前缀与语义参数。写入验证有限、非零 float32；查询先通过 MATERIALIZED 集合过滤空间、维度、书本、当前版本及可选子树，再通过 CASE 保护执行距离计算。

关键词按 FTS5 BM25 排序，向量按余弦距离排序；同分以稳定块 ID 排序。短语属于关键词匹配，按规范化连续原文查找并按书本、文档顺序返回。目录树、概述、概念与有证据关系保留为可单独浏览／读取的工具，不再为搜索结果添加排序权重或隐式扩展相邻块。目录范围在搜索前限定任意子树，别名仍写入 FTS。默认只调用关键词，需要时可独立调用向量，或显式指定两种方式的顺序；按顺序追加去重，各自排序保持不变。

返回 `book_title/path/score/method/rank`，顺序查询额外返回 `step`；分数仅能在同一种方式内解释，不能视为置信度。`path` 不含教材页码。关键词、短语与向量均有每种输出条数上限，Web 与 LLM 工具在服务端验证；正文与目录读取范围仍独立校验。

数据库恢复或词法规则改变后，`RetrievalService.rebuild(book_id)` 重建该书 FTS；嵌入由 `embedding_targets/store_embedding` 重新生成。内容改动期间 FTS 保持可用，过期空间向量不会混入新查询。

## 历史恢复

`restore:{id,base_revision,restore_revision}` 读取本书对应块的历史版本，并创建新的正式版本。普通文本回退不会减小版本号或删除历史。若跨越合并／拆分，或者恢复目标已经重定向，单块操作拒绝并返回 `restore_requires_topology_group` 及关联 ID；必须在同一操作组列出所有拓扑关联块的 `restore`。`restore_revision:null` 表示归档后来拆分生成的块。恢复组只包含恢复操作，不与普通编辑混合。

整组恢复同时重建正式内容、当前重定向、FTS、失效向量和当前证据。已取消的重定向保存为 `current_id:null/active:false` 的当前墓碑，使再次合并仍可沿用递增历史版本；解析器将其视为没有重定向。旧快照与重定向历史不删除。引文回迁到恢复后的块必须唯一匹配；歧义或跨块证据标记失效。
