# v0.1 实施与验收记录

更新日期：2026-09-07。实现与自动验证在 Linux x86_64 本机完成。最初使用无外部模型的隔离夹具验收；随后在用户授权的本地配置上完成 DeepSeek 两款模型的简短连接与工具提交测试，那次连接测试未发送真实教材或题目。模型用途拆分仅使用临时数据库、模拟 HTTP transport 与独立浏览器响应夹具。最新的上传上限调整仅使用临时数据库与 TestClient 验证，未启动或重启运行中的后端。

## 已实现的功能范围

- 单用户密码登录、会话／CSRF、显式局域网来源、桌面与移动布局；外观为图标三段式单选，支持浅色／深色／系统主题、键盘切换和本地偏好保存。
- 首页的真实最近错题、教材与待处理任务，按配置显示的开始步骤，录入／导入和已有记录深链接；原创品牌 SVG、统一导航图标及独立琥珀色教材提示。
- 四种题型的草稿录入、参考解析图片／文本、人工确认答案、输入变更后讲解过期、教材范围和有出处的结构化讲解。
- 教材文本／文件／图片／PDF 导入，EXIF 归正、HEIF 转换和裁剪；任意目录树、顺序修订、可选上下文预算、人工保护、页面手工校正／重新识别／跳过、建议差异审阅、版本恢复。已去除自动质量分级与补救调用，旧待校对页在启动时转为草稿。
- 单文件默认上传上限为 1 GiB（1024 MB），环境变量可覆盖；后端启动时读取，等于上限允许上传，超限拒绝。
- 一次性操作组回执、块合并／拆分、当前重定向与证据投影、规范化引文坐标、概念证据硬校验。
- Chat Completions／Responses、可留空且默认不传的最大输出、默认留空且应用不再施加隐含长度限制的上下文预算、嵌入、两级并发、预约和窗口、工具循环检查点、在途任务续租及迟到结果拒绝。
- 教材分阶段持久进度、跨页面任务状态恢复、事务内重复提交保护、失租／接口失败提示，以及按处理单元和请求边界实施的模型配置热重载。
- 教材图片／文本、题目图片／文本四份生成配置与独立嵌入配置；启动时原子拆分旧视觉／讲解记录，参数完整继承，后续独立编辑／删除和共享并发额度。
- FTS5、共享 jieba 词法模块、别名、空间／维度隔离的向量查询、目录与概念辅助混合检索。
- 练习／复习 PDF、固定快照、独立配图、中文及公式字体、字体／图片失败检查。

模型用途拆分复用临时 SQLite 与 TestClient，分别验证 Web 先启动、worker 先启动及同时检测：旧两份生成配置变为四份、嵌入保持不变，连接、Key、协议、思考、窗口、并发及可空预算逐字段继承。后续改题目文本配置不改变教材文本，重启不覆盖编辑或补回主动删除项，API 不泄露 Key。旧教材续接样本加入 `chat` 转换，仍原样复用兼容的工具历史；串联流程对教材修订／概述、纯文本题目、参考图提取和讲解断言不同实际模型 ID，教材图片走专属图片模型。共享桶测试覆盖四个新用途。

模型用途界面已用 Chromium 在本地路由夹具中检查列表、五种用途选项、教材文本职责说明及桌面／移动布局。报告位于 `.verification/task-ui-1788789300378096903/report.json`，`separate_model_purposes` 列出五种用途，`app_processes_started=false`、`external_model_requests=0`、`browser_errors=[]`。已人工查看 `models-mobile-dark.png` 与 `model-purpose-desktop-dark.png`。这不代表已对当前业务库执行转换或在真实服务商验收新配置。

后端验证只覆盖容易产生协议错误或数据损坏的边界，没有覆盖率目标：

1. **模型协议**：锁定 OpenAI Python SDK 3.8.0，通过 HTTP transport 夹具验证思考三态、参数冲突、双协议工具续接、两种存储模式、推理项保留和一次格式修复。最大输出复用工具循环场景：覆盖 Chat 的两种输出字段与 Responses 字段，缺省／显式 `null` 在 SDK 实际发送的 JSON 中完全缺席、正整数正确映射，首轮和工具续接均检查；另外拒绝 0／负数。上下文预算缺省／`null` 时完整请求和材料组织均无默认上限；SDK 请求不发送内部字段，扩展 JSON 不能绕过这一约束。超过用户显式请求上限时，在调用前拒绝并显示估算值和设置值；Chat／Responses 的长思考项从检查点完整续接。
2. **执行与事务**：真实临时 SQLite、跨进程认领／共享与独占锁、失租提交拒绝、阻塞工作期间心跳、等待依赖不阻塞后续任务、两级并发取消释放、跨午夜窗口、认证／答案／快照边界。新增场景复用真实临时库：跨进程同一资源入队只产生一个任务、互斥类型返回冲突、旧任务不能与替代任务同时恢复；超过 100 条后仍返回未结束任务，进度不含原始工具转录／图片。API 复用题目／教材／搜索／导出去重样本，模型保存只重新检查窗口等待，不提前未来预约。
3. **教材一致性**：合成长期上下文、无损处理单元、缺口、保护内容建议、一次性接受／拒绝回执、合并重定向、拆分和成组恢复、历史快照不改写。扩展同一长书样本，验证整页／工具说明／工作记忆超过旧 24000 仍完整保留、读取大块无隐含限额，显式预算包含元信息后不超限。
4. **检索与证据**：Unicode 与码点、空白、重复引文、标点／OCR 差异拒绝、别名与转义、跨教材隔离、多维向量、双向关系数量上限、当前证据失效。

真实 SQLite 的串联流程覆盖教材页草稿→正式块／概念／FTS→概述／嵌入→错题提取→用户确认→引用讲解，同时使用上下文预算留空的讲解和嵌入模型配置检查教材修订、概述与嵌入分批正常完成。模型返回值使用可复现夹具；这不证明真实模型的内容质量。

中断续接使用两种参数化夹具（旧检查点、新输入快照），在临时 SQLite 中准备已完成页、已识别页和跳过页，模拟第二页工具返回后的中断，再经 TestClient 调用续接接口。验证预约时间生效、重复点击不改期、原任务保留、已完成页／块不变，继续后完成正文处理；来源修改或删除不能复用旧结果。旧检查点配置不变时保留完整思考／工具结果；新检查点场景把保存的旧材料总预算设为 512 并修改模型和 effort，验证旧预算不再拦截、实际 HTTP 请求采用最新模型和参数，未混入旧工具链。长书样本验证设置变化后固定单元边界不移动。SDK 夹具检查图片请求及指纹保存，不重复保存 Base64。这些检查仅用临时库、TestClient 和 HTTP transport，没有连接现有业务数据库、启动应用服务或调用真实模型。

启动恢复样本直接执行临时库的 worker 启动钩子并禁用任务调度，验证 AI 候选、人工文本、空白候选及无候选回退；旧页面转换为草稿且历史保留，第二次扫描不重复写入。已完成／跳过／草稿页和删除教材不变，旧质量等待可重新排队且预约及检查点保留，失败／取消或其他人工等待不自动重开；识别进度随恢复状态增加。并行页识别夹具返回旧 `quality=uncertain` 和断句问题，实际新工具定义不包含质量字段，16 页只执行 16 次识别且继续完成正式整理。

长内容索引样本使用预算留空的模型，一次概述请求携带两个完整节点，再生成根概述；正文和节点向量同批提交，不因旧默认 token 预算切分。预置的旧首段概述缓存不会冒充整节点结果，验证取消材料限制后的缓存边界。

热重载验证使用 Chat／Responses 参数化夹具：在读取工具后修改模型、协议、凭据及思考参数，当前链仍发送原配置；未完成链恢复时使用新配置且不混入旧推理项。另复用两种协议检查工具结构变化也重建未完成链，已完成结果不再次调用。等待名额时提升上限可放行下一请求，已有在途请求保持运行。嵌入场景在第一批返回时将模型与维度从 3 改为 4，原任务重新规划新空间，旧批次不会被错标。串联流程同时检查搜索向量调用的用量投影。

移除后台任务与教材识别的额外 8 并发限制后，使用两个参数化场景验证：16 个独立任务、同一本教材的 16 页草稿。两者均使用真实临时 SQLite、实际 SDK 和异步 HTTP transport 夹具，在首批返回前达到配置的 12 个在途请求，整个流程也未超过 12；原有两级并发测试继续验证凭据合计限制。教材识别结束后仍按原始页序完成正式修订。此次没有启动应用服务或调用真实模型，也没有为纯后端变动重复浏览器／PDF 验收。

此前 DeepSeek 官方端点的 `deepseek-v4-flash` 与 `deepseek-v4-flash-vision-exp` 已通过真实 worker 的 `model_test`。当次测试均使用 Chat Completions、`thinking.type=enabled`、`reasoning_effort=max`、`max_tokens`，并在配置中显式选择 `tool_choice=omit`。初次强制工具选择的请求返回 400；改用显式省略策略后，两款模型各一次请求返回 `ok=true`。这证明当次凭据可完成简短文本工具提交，不代表图片识别、长工具链或整本教材的质量已验收；最大输出默认省略的本次改动使用 SDK 夹具验证，没有因此重复调用真实模型。凭据和本地配置不进入代码仓库。

错因功能复用该流程验证：缺省关闭、勾选后优化、空白原文不优化、取消勾选后不保留新结果，模型擅自生成的未授权优化内容被丢弃；原文、备注和答案确认状态保持不变，每次讲解没有新增独立润色调用。API 样本验证错因修改使讲解过期；前端样本验证旧记录兼容与过期结果隐藏。真实 Chromium 移动视口下已验证原文输入、默认未勾选、保存、勾选后再次保存和重新载入；报告 `error_reason_saved_and_reloaded=true`，截图为 `mobile-error-reason.png`。

## 用户流程与视觉验收

本次进度与热重载修改遵循“不启动应用进程”的要求：没有运行 Web／worker，也未调用真实服务商。后端使用临时 SQLite 和 TestClient；前端使用 `scripts/verify_task_ui.py` 读取本地构建，由 Playwright 路由提供响应夹具。最新报告位于本机 `.verification/task-ui-1788702707352165809/report.json`，记录 `app_processes_started=false`、`external_model_requests=0`、`search_restored_after_reload=true`、`unsaved_page_edits_preserved=true`、`home_shares_task_progress=true`、`expired_lease_and_api_failure_guarded=true`；书本、原页、题目、模型测试、导出和检索入口均验证了未结束任务保护。实际检查 1280px 桌面与 390px 深色移动截图，无横向溢出及浏览器错误。该验证不等于已把新代码放入运行中的应用验收。

`scripts/verify_local.py` 创建独立 `.verification/run-*/`，实际启动服务并登录，生成练习／复习 PDF，下载后重新打开并检查 A4 尺寸、中文可提取文字、答案显示隔离和配图。导出的 PDF 再通过隔离 PDFium 进程导入，验证逐页正文与预览图生成。

浏览器验收覆盖 1440 像素桌面与 390×844 移动视口、暗色、题目及模型表单，检查横向溢出和浏览器异常。阻断 Noto 字体请求后，导出页面明确报告失败。截图、PDF、服务日志及 `report.json` 保存在对应运行目录，验收完成后进程退出。

模型表单场景同时检查最大输出默认空白且非必填；填入 2048 后启用 Chat 输出长度字段选择，清空后恢复禁用。结果记录在 `optional_output_limit`；是否省略实际请求字段由上述 SDK transport 夹具验证。

此前上下文预算复用同一模型表单场景，检查默认空白、非必填、填写数值及再次清空；结果记录在 `optional_context_limit`。本次同步更新提示文案并通过前端测试、格式检查及生产构建；材料／请求预算行为由上述后端夹具验证，未重复运行应用或真实浏览器流程。留空表示应用不设上下文上限，服务商自身限制仍生效。

首页改版验收另外覆盖最近题目／教材链接、录入／导入快捷入口，以及 320px 窄屏、浅色／深色的空首页和教材提示条。空资料库通过独立浏览器上下文的列表响应夹具实现，不清空数据库。报告记录 `home_shortcuts_and_recent_links=true` 与 `empty_home_and_notice`；截图以 `home-`、`notice-mobile-` 开头。品牌图标同时检查了小尺寸渲染；没有为静态布局增加单元测试。

外观切换复用空资料库浏览器场景：按 `radiogroup`「外观主题」内的原生 radio 选择，验证方向键从浅色切到深色时只有一项选中、刷新后选择保留、跟随系统时响应颜色变化，以及固定浅色不受系统深色影响。结果记录在 `theme_switch`；桌面浅色／深色、320px 与 390px 移动截图包含新控件，不为静态样式增加单元测试。

最终分页调整后的本机结果：练习版 2 页，加入长解析样本的复习版 4 页，复习 PDF 成功重新导入 4 页；浏览器异常为零，字体故障被检出。人工查看中文、公式、配图和移动弹窗截图；短题的题干／配图／作答区保持成组，长解析可跨页。
