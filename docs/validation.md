# v0.1 实施与验收记录

更新日期：2026-09-09。实现与自动验证在 Linux x86_64 本机完成。最初使用无外部模型的隔离夹具验收；随后在用户授权的本地配置上完成 DeepSeek 两款模型的简短连接与工具提交测试，那次连接测试未发送真实教材或题目。模型用途拆分、题目公式整理与格式重试修改使用临时数据库、模拟 HTTP transport 与独立浏览器响应夹具。上一轮数组编码兼容排查只读查看了现有任务检查点，并在内存中重新校验保存的工具参数；未修改业务数据库，未启动或重启 Web／worker，未发真实模型请求。

## 已实现的功能范围

本轮教材整理修复使用模拟 HTTP 与真实临时 SQLite，覆盖：工具读取失败后仍有独立的最终格式修复机会（Chat／Responses 两种存储模式）、504 重试与安全诊断、旧结构下被拒绝的正文在升级后零额外模型请求恢复、错误概念／关系单独审计及无原文证据拒绝。任务 UI 夹具扩展了正文与 OCR 计数分离、工具活动展开、流式阶段和 504 提示的移动端／桌面检查。本轮不操作业务数据库，不启动或重启 Web／worker，不发送真实模型请求；模拟验证不代表中转的 300 秒截止限制已解除。

- 单用户密码登录、会话／CSRF、显式局域网来源、桌面与移动布局；外观为图标三段式单选，支持浅色／深色／系统主题、键盘切换和本地偏好保存。
- 首页的真实最近错题、教材与待处理任务，按配置显示的开始步骤，录入／导入和已有记录深链接；原创品牌 SVG、统一导航图标及独立琥珀色教材提示。
- 四种基础题型与可持续嵌套大题的草稿录入、参考解析图片／文本、人工确认答案、输入变更后讲解过期、教材范围和有出处的结构化讲解。
- 题干与选项在同一次 AI 整理请求中优化表述与公式排版；兼容已有文本与图片输入，有歧义的已有字段保留原文并显示核对提示，原选项 ID、顺序、用户答案及历史受保护。
- 教材文本／文件／图片／PDF 导入，EXIF 归正、HEIF 转换和裁剪；任意目录树、顺序修订、可选上下文预算、人工保护、页面手工校正／重新识别／跳过、建议差异审阅、版本恢复。已去除自动质量分级与补救调用，旧待校对页在启动时转为草稿。
- 单文件默认上传上限为 1 GiB（1024 MB），环境变量可覆盖；后端启动时读取，等于上限允许上传，超限拒绝。
- 一次性操作组回执、块合并／拆分、当前重定向与证据投影、规范化引文坐标、概念证据硬校验。
- Chat Completions／Responses、可留空且默认不传的最大输出、默认留空且应用不再施加隐含长度限制的上下文预算、嵌入、两级并发、预约和窗口、工具循环检查点、在途任务续租及迟到结果拒绝。
- 模型格式错误按既有 `retries` 配置重试，覆盖没有工具调用和 JSON／字段错误，附简洁校验反馈；重试耗尽后可续接当前单元，保留原进度和已执行工具结果。
- AI 数组兼容单键 `item` 包装和 JSON 数组字符串；只转换明确编码并完整验证元素。继续任务时可重验最后一次被拒绝的独立提交，通过后直接复用，不再次请求模型；原始工具记录与用量保留。
- 教材分阶段持久进度、跨页面任务状态恢复、事务内重复提交保护、失租／接口失败提示，以及按处理单元和请求边界实施的模型配置热重载。
- 教材图片／文本、题目图片／文本四份生成配置与独立嵌入配置；启动时原子拆分旧视觉／讲解记录，参数完整继承，后续独立编辑／删除和共享并发额度。
- FTS5、共享 jieba 词法模块、别名、空间／维度隔离的向量查询、教材与题目的独立关键词／向量检索、显式顺序追加去重及每种条数上限。
- 练习／复习 PDF、固定快照、独立配图、中文及公式字体、字体／图片失败检查。

- 默认 SSE 生成请求、可关闭流式与用量扩展，任务详情显示首末接收及正文／推理／工具参数字符数。
- 预设科目复用同名 ID，重命名不丢关联，不重新补回改名后的旧预设。
- 多层大题、文本／听力材料、独立 ASR／TTS 配置，缺失项补全及已完成音频阶段恢复；可选安全 SVG／函数坐标图与上传插图。
- 设置用途分组、科目管理与检索目录范围；练习隐藏听力文稿且只为简答留白，复习保留错因和详细依据。

后端验证只覆盖容易产生协议错误或数据损坏的边界，没有覆盖率目标：

1. **模型协议**：锁定 OpenAI Python SDK 3.8.0，通过 HTTP transport 夹具验证思考三态、参数冲突、双协议工具续接、两种存储模式、推理项保留、格式重试与耗尽续接。最大输出复用工具循环场景：覆盖 Chat 的两种输出字段与 Responses 字段，缺省／显式 `null` 在 SDK 实际发送的 JSON 中完全缺席、正整数正确映射，首轮和工具续接均检查；另外拒绝 0／负数。上下文预算缺省／`null` 时完整请求和材料组织均无默认上限；SDK 请求不发送内部字段，扩展 JSON 不能绕过这一约束。超过用户显式请求上限时，在调用前拒绝并显示估算值和设置值；Chat／Responses 的长思考项从检查点完整续接。
2. **执行与事务**：真实临时 SQLite、跨进程认领／共享与独占锁、失租提交拒绝、阻塞工作期间心跳、等待依赖不阻塞后续任务、两级并发取消释放、跨午夜窗口、认证／答案／快照边界。新增场景复用真实临时库：跨进程同一资源入队只产生一个任务、互斥类型返回冲突、旧任务不能与替代任务同时恢复；超过 100 条后仍返回未结束任务，进度不含原始工具转录／图片。API 复用题目／教材／搜索／导出去重样本，模型保存只重新检查窗口等待，不提前未来预约。
3. **教材一致性**：合成长期上下文、无损处理单元、缺口、保护内容建议、一次性接受／拒绝回执、合并重定向、拆分和成组恢复、历史快照不改写。扩展同一长书样本，验证整页／工具说明／工作记忆超过旧 24000 仍完整保留、读取大块无隐含限额，显式预算包含元信息后不超限。
4. **检索与证据**：Unicode 与码点、空白、重复引文、标点／OCR 差异拒绝、别名与转义、跨教材隔离、多维向量、双向关系数量上限、当前证据失效。

真实 SQLite 的串联流程覆盖教材页草稿→正式块／概念／FTS→概述／嵌入→错题提取→用户确认→引用讲解，同时使用上下文预算留空的讲解和嵌入模型配置检查教材修订、概述与嵌入分批正常完成。模型返回值使用可复现夹具；这不证明真实模型的内容质量。

格式重试在 SDK 夹具中覆盖 Chat、Responses 无状态与服务端存储：先返回自由文本，再返回含未知键的歧义数组包装，最后正确提交；同一链保留原推理项、工具反馈和 call_id，默认两次重试足够完成，正常工具轮数设为 1 仍可修复。中途模拟窗口关闭并序列化检查点，恢复前把次数从 1 调为 2，验证不重复消耗已安排的重试且最新次数生效。另验证 0／2 次额度下分别仅有 1／3 次请求，耗尽状态不会因自动恢复刷新。歧义数组包装样本只产生三个真实字段错误，不再叠加无关操作分支。教材续接复用原长书夹具：前页已完成，当前页字段错误耗尽后通过真实恢复 API 继续，校验反馈保留，坏参数不落入正文，前页和已经返回结果的读取工具不重跑。所有用量按实际夹具返回累计。

数组编码使用两个参数化样本覆盖单键 `item` 的单值／多值及嵌套 JSON 数组字符串，确认不改写原始参数、正文、引文或可接受字符串的答案字段；普通字符串、伪 JSON、额外键、无效元素和缺失操作类型仍拒绝。教材、题目、讲解及概述四种 JSON Schema 的修改前后指纹实际比较一致，不迫使既有工具链重建。三种 SDK 模式模拟旧 `list[str]` 校验拒绝，再按新规则续接，确认无需第二次模型调用、原始转录及用量不变；Chat 另去掉新增候选字段以覆盖旧检查点恢复。未完成批次、多工具提交、call_id 不匹配，以及已被新回复取代的候选均不恢复。临时 SQLite／TestClient 场景验证这种恢复确实提交了当前页，同时保留已完成页、原操作记录与来源版本检查。

现有失败任务的最后一次返回经 `mode=ro`／`query_only=ON` 连接读取，在内存中使用新的 `RevisionDraft` 成功校验；未把候选写入业务库，未执行真实任务或模型请求。这只证明该返回通过当前结构校验，实际续接仍须经过正常的业务、版本和租约校验。该轮未修改前端，因此没有重复执行当时已通过的浏览器及 PDF 验收。

题目公式整理新增五个参数化场景：已有文本、图片及空白占位选项、有歧义的题干／选项、旧缓存结果、不完整候选 ID。前三种经过实际 worker 分发、SDK 与临时 SQLite，验证每次仅一次模型请求、分别选择题目文本／图片模型、按原 ID 保留选项顺序、受影响字段保留原文、原答案／作答／备注／错因不被覆盖、撤销答案确认及保留历史。旧缓存经序列化恢复后仍只补空字段；候选 ID 不完整时保留原选项并提示。这些夹具证明结果接收与状态行为，不证明真实模型能始终保持题意或正确转换公式。

中断续接使用两种参数化夹具（旧检查点、新输入快照），在临时 SQLite 中准备已完成页、已识别页和跳过页，模拟第二页工具返回后的中断，再经 TestClient 调用续接接口。验证预约时间生效、重复点击不改期、原任务保留、已完成页／块不变，继续后完成正文处理；来源修改或删除不能复用旧结果。旧检查点配置不变时保留完整思考／工具结果；新检查点场景把保存的旧材料总预算设为 512 并修改模型和 effort，验证旧预算不再拦截、实际 HTTP 请求采用最新模型和参数，未混入旧工具链。长书样本验证设置变化后固定单元边界不移动。SDK 夹具检查图片请求及指纹保存，不重复保存 Base64。这些检查仅用临时库、TestClient 和 HTTP transport，没有连接现有业务数据库、启动应用服务或调用真实模型。

启动恢复样本直接执行临时库的 worker 启动钩子并禁用任务调度，验证 AI 候选、人工文本、空白候选及无候选回退；旧页面转换为草稿且历史保留，第二次扫描不重复写入。已完成／跳过／草稿页和删除教材不变，旧质量等待可重新排队且预约及检查点保留，失败／取消或其他人工等待不自动重开；识别进度随恢复状态增加。并行页识别夹具返回旧 `quality=uncertain` 和断句问题，实际新工具定义不包含质量字段，16 页只执行 16 次识别且继续完成正式整理。
