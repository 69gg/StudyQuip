# StudyQuip

个人错题与教材学习工作台。作者 **Null** · **pylindex@qq.com** · **MIT License**。

上传教材，校对 AI 整理的正文与目录，再录入错题、确认答案、生成有来源的讲解，最后导出练习或复习 PDF。支持手机上传与拍照、任意目录层级、浅色／深色界面和延迟处理。

## 启动

需要项目固定的 **uv 0.12.10**、**Node.js 22** 和 **pnpm 11.3.0**。Python 固定为 uv 托管 **CPython 3.13.15 / PBS 20260901**，官方构建下载元数据地址在 `pyproject.toml`。第三方 Python 和前端依赖分别锁在 `uv.lock` 和 `frontend/pnpm-lock.yaml`。

在项目根目录执行：

```sh
uv sync --locked --managed-python --python 3.13.15
uv run studyquip doctor
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend build
uv run playwright install chromium
uv run studyquip init
uv run studyquip run
```

`init` 会检查真实 SQLite 能力、显式迁移，并交互设置至少 8 个字符的登录密码。打开 **http://127.0.0.1:8765**。`run` 同时启动 Web 与唯一 worker，Ctrl+C 一起停止。

需要分开管理进程时，在两个终端运行：

```sh
uv run studyquip web
uv run studyquip worker
```

worker 负责全部模型请求、模型连接测试、后台教材处理和 PDF 渲染。生成 PDF 时 Web 也必须运行，供 Chromium 读取独立的导出页面。

## 使用流程

登录后默认进入首页，可以继续打开最近的题目或教材，查看需要处理的任务，也可以直接录入错题、导入教材。首次使用时，首页根据当前资料与模型配置显示开始步骤。侧栏和手机顶部导航都能返回首页。

1. 设置页分为模型连接与科目管理；预设生物、化学、物理、英语、数学，复用已有同名科目，重命名保留原 ID 和资料关联。分别配置教材图片、教材文本、题目图片、题目文本及向量嵌入模型。填入服务商 Base URL、API Key、实际模型 ID 和 API 协议；不同用途可以使用同一模型。同用途有多个配置时，当前使用最早配置，删除前请检查运行任务。
2. 在教材页输入书名与科目，粘贴文本或上传 PDF、多张图片／文本文件，调整输入顺序，再选择立即或预约处理。按原始顺序进行正式修订，页草稿识别可并行。
3. 在教材工作台检查目录和正文。目录保留原书名称，允许任意深度；正文可修改、拆分、合并、归档及查看历史。人工修改受保护，AI 的相关修改进入建议队列，采纳前显示差异并校验版本。
4. 遇到识别困难的页面，可以重新识别、手动校正、跳过或明确采用 PDF 可提取文字。跳过会保留缺口，后续 AI 不会跨缺口拼接段落。
5. 录入一道错题，填写或由 AI 整理题干、题型、选项、原作答，上传可选参考解析。“AI 整理题目”可以润色题干和选项表述，并将含义明确的公式规范为 LaTeX，支持已有文本与图片识别；不改题意、数值或条件。有歧义的已有字段保留原文并提示核对，原内容保存在版本历史中。题干或选项有变化后，请在预览中检查并重新确认答案。正确答案只能由用户填写或从参考资料提取，**必须由用户确认**。备注始终由用户编辑。
   “做错原因”由用户填写，可以留空；“让 AI 优化表述”默认不勾选。勾选且有原文时，在生成讲解的同一次请求中优化表达，原文始终保留，优化结果单独显示。修改错因或开关会使旧讲解待更新，不影响正确答案确认。
6. 选择相关教材；不选时检索同科目全部教材。生成讲解和知识点。引用显示书名和真实目录路径，不显示教材页码。无原文命中时明确显示缺少教材依据。
7. 勾选错题并调整顺序，导出 PDF。练习版只含做题所需题干、材料、选项和插图，只有简答题留空行，听力文稿不打印；复习版包含所选答案、讲解、知识点，以及原错误作答、做错原因和教材来源，听力文稿可见。练习配图独立选择，请使用干净的题图，不直接使用带答案批改的原始照片。

支持大题持续嵌套：将任意节点设为“大题”，添加基础题或继续添加大题。通过“当前编辑位置”目录切换，增删或调整小题顺序；每个节点可有文本材料、听力材料和插图，整题统一选择科目与教材并确认全部答案。保存时保留已有子题 ID、解析和历史，修改相关内容后解析过期。

听力材料可以放在整题、大题或单个小题上，录音／文稿至少一项，也可同时上传。在设置的“听力”组分别配置语音识别与语音合成模型；兼容 `/audio/transcriptions` 与 `/audio/speech`，合成需填音色。保存时对已配置的缺失项自动安排补全，也可点击“补全听力资料”预约；未配置时保留原材料并提示，两个都有则不调用。AI 合成音频有明确标记，修改合成来源文稿后再次保存可重生成；用户原始录音不会被覆盖。只有录音而无文稿时，先补全文稿再生成讲解。

题目插图可选上传，也可使用静态安全 SVG 或可编辑函数／坐标图，预览与 PDF 共用渲染。AI 无法可靠复刻时提出上传要求，用户需补图或明确核对已有图足够；原始题图和含批改的图片不自动当作练习配图。检索页支持教材与错题两个范围。默认只用关键词，可切换独立向量检索；需要时手动添加第二种并调整顺序，按顺序追加去重，不融合分数。关键词可选任意词／全部词／连续原文，并设置每种检索的最大返回条数。教材可限定科目、书本与任意目录子树。

题目保存及 AI 更新后，题干、选项、答案、解析、知识点、材料、参考解析和错因自动分别建立索引，支持多层大题。关键词索引随保存立即更新，worker 自动补齐变化部分的向量；未改变的部分复用原向量，过期解析不参与检索。可单选或多选检索部分，叠加科目、题型条件；打印窗口的“检索相关题并加入打印”复用这些条件，只列出答案已确认的题目，支持加入、去重、排序和移除。

此次题目索引新增数据库迁移 `0002`。已有安装需由用户停止 Web/worker 后运行 `uv run --locked studyquip upgrade`，再启动新版应用；启动时自动补齐旧题目的索引，不改题目 ID、原内容或版本。详见 [升级与运行](docs/operations.md#题目分部索引与独立检索升级)。

第一版没有连续追问聊天界面，也没有多用户数据隔离。

教材详情会持续显示原页识别、正式整理、待校对／跳过页数、目录概述和向量索引进度；任务页补充正在处理的原页、模型与配置版本、请求等待、执行尝试及已记录用量。错题、页重新识别、模型测试、检索和 PDF 导出也会恢复未结束的任务。刷新或切换页面不会重新开放重复提交入口；后端在事务中复用已有同类任务。任务状态获取失败或 worker 租约过期时，会显示原因并保留提交保护。

## 模型、时间窗口与并发

DeepSeek V4 开启思考时，工具选择策略设为“不发送（服务商默认）”；最大输出默认留空，若需指定上限，输出长度字段使用 `max_tokens`。需要较高思考强度时填写 `max`。应用仍要求模型通过工具提交结构化结果。[具体协议与参数说明](docs/ai-runtime.md)

教材与题目的图片、文本模型均支持 Chat Completions、Responses，嵌入模型使用 Embeddings API。所有结构化输出经过工具调用及应用校验。

| 模型用途 | 负责的处理 |
|---|---|
| 教材图片模型 | 教材图片、PDF 页面的识别与插图描述 |
| 教材文本模型 | 正式正文整理、跨页续接、目录概述及修改建议 |
| 题目图片模型 | 题目图片和参考解析图片的字段提取、题干与选项公式整理 |
| 题目文本模型 | 纯文本题目及公式整理、讲解、知识点及已勾选的错因优化 |
| 向量嵌入模型 | 教材与查询文本的向量检索 |
| 语音识别模型 | 听力录音转文稿 |
| 语音合成模型 | 听力文稿转录音，指定音色和可选语速 |

旧版本升级后，启动 Web／worker 时会自动拆分已有配置：旧视觉模型复制到教材图片和题目图片，旧讲解模型复制到教材文本和题目文本；地址、Key、协议、思考参数、预算、时段与并发设置全部继承，嵌入配置保留。此转换只执行一次，之后分别编辑互不覆盖，主动删除的用途也不会在下次启动时重新补回。同端点、Key 和实际模型仍共享并发额度。

- Chat／Responses 默认流式，可在模型设置中关闭；旧配置缺少此字段时自动按开启读取。任务详情显示首包等待、最后接收时间、正文／思考／工具参数字符数及工具名称，不展示完整思考内容。Chat 可单独关闭流式用量统计以兼容服务商；断流且未收到完整终态时按网络重试，部分响应不提交。
- 思考扩展分为“不发送 / enabled / disabled”；`thinking` 是特定服务商扩展，使用 OpenAI 官方接口时默认不发送。
- effort 使用服务商实际接受的值；Chat 映射到 `reasoning_effort`，Responses 映射到 `reasoning.effort`。
- 最大输出默认不传，留空时采用服务商默认上限；填写正整数才发送对应参数。已有的数字上限继续生效，清空并保存即可取消。
- 上下文预算默认留空，表示应用不设置上下文上限，教材材料组装、正文读取、概述和嵌入分批也没有默认 24000 回退值。教材按原页组织，使用相关前后文；只有显式填写模型预算时才按长度分段、控制材料和检查完整工具请求。此字段不发送给服务商，服务商自身限制仍生效。旧环境变量 `STUDYQUIP_CONTEXT_TOKENS` 已移除，残留值会被忽略。
- 任务失败或中断后，有保存进度时可在任务页或教材详情点击“继续处理”，选择立即或预约续接。执行时读取最新模型配置，复用原任务、已识别页面及已完成正文；配置未变时复用工具上下文，配置或工具结构改变则重建未完成的工具链。输入已修改或来源已删除时会说明不能续接的原因，旧检查点保留。
- 教材识别成功后直接保存草稿，不再让模型判断质量等级，也不再因页尾断句补救识别或暂停整理。用户启动新版 worker 时，旧待校对页自动转为草稿：保留人工编辑，否则使用已保存的 AI 候选文本，没有候选时保留当前文字。原件和历史保留；页面仍提供手工校正、重新识别与跳过。
- 可设置采样参数、超时、自动重试次数、工具轮数和扩展 JSON；冲突字段明确报错。“自动重试次数”默认 2，网络错误与模型格式错误分别使用此次数，0 表示关闭自动重试。没有调用结果工具、JSON 或字段格式错误都会带反馈重试当前单元；已识别页和已完成正文不重跑。次数用完后可点击“继续处理”，按最新模型配置续接。
- AI 数组字段兼容仅含 `item` 的包装及 JSON 数组字符串，转换后仍完整校验字段、元素和业务约束，不猜补缺失内容。“继续处理”会优先重验已保存的最后一次独立结果提交；配置兼容且校验通过时直接复用，不再请求模型，原始工具记录保留。
- Responses 默认显式 `store=false`，保留加密推理项和完整工具续接记录；切换为 `store=true` 后按已存储项 ID 引用。
- 每个模型桶默认 4 并发。同凭据、端点、模型的角色／协议共享名额；可选凭据总并发上限叠加在全部模型上。
- worker 和教材原页识别不再叠加独立的任务数／页数并发上限；可并行请求统一遵守模型及凭据的配置。正文跨页修订仍按教材顺序提交。
- 可设置预约时间、延迟及每天多个允许请求时间段，默认 `Asia/Shanghai`、全天。时间窗口按每次请求重新检查；已发出的请求允许结束。时间窗口由用户配置，应用不会自动查询服务商峰谷价格。
- 任务页显示排队原因、阶段、请求用量、失败信息及重试／改期／取消操作。凭据并发上限不等同于 RPM 限制。

**模型配置保存后无需重启应用。** 未开始的处理单元读取最新配置；教材每页修订、下一次概述调用和嵌入批次都会重新读取。已经发出的请求及同一单元的工具调用链使用原模型、协议和生成参数完成，下一单元再切换。并发、时段、超时与重试在后续请求中重新检查；修改时段会唤醒原先等待时段的任务重新判断，不会提前用户预约的排队任务。更换嵌入模型或维度会按新空间重新计算缺失向量，保留当前关键词检索。`.env` 中的应用级配置仍需重启。

详细协议见 [模型与任务运行协议](docs/ai-runtime.md)、[教材修订与证据协议](docs/textbook-protocol.md)。

## 手机与局域网

默认只监听 `127.0.0.1`。需要手机访问时，显式设置监听地址和允许的浏览器来源，例如电脑地址是 `192.168.1.20`：

```sh
STUDYQUIP_HOST=0.0.0.0 STUDYQUIP_ALLOWED_ORIGINS='["http://192.168.1.20:8765"]' uv run studyquip run
```

Windows PowerShell 使用 `$env:STUDYQUIP_HOST='0.0.0.0'` 和 `$env:STUDYQUIP_ALLOWED_ORIGINS='["http://192.168.1.20:8765"]'` 设置同名变量，再运行启动命令；也可参考 `.env.example` 创建 `.env`。

手机打开电脑的局域网地址。拍照使用浏览器文件选择能力，提供单独的相册入口；实际相机交互由手机浏览器决定。图片归正后裁剪，原始文件保留，支持 HEIC/HEIF。

HTTP cookie 使用 `HttpOnly`、`SameSite=Lax`，不设置 `Secure`；修改接口使用 CSRF token 与来源校验。**这套 HTTP 配置仅用于本机或可信局域网，不要暴露公网。**

## 配置与数据

配置由 `STUDYQUIP_` 前缀的环境变量或 `.env` 提供，完整默认值见 `src/studyquip/config.py`。常用项见 [运行与配置](docs/operations.md)。

单文件上传默认上限为 **1 GiB（1024 MB）**，教材与题目附件共用此限制；可通过 `STUDYQUIP_MAX_UPLOAD_MB` 调整。该应用级配置在后端启动时读取，更新代码或 `.env` 不会改变正在运行的后端上限。

默认 `data/` 保存 SQLite 数据库、不可变原件、派生图片与 PDF、应用密钥和持久锁文件。模型凭据保存在应用数据库中；该目录不纳入版本库，备份时与教材一起妥善保存。

更改密码使用 `uv run studyquip password`，旧会话会失效。升级前停止 Web 和 worker，备份完整数据目录，再执行 `uv run studyquip upgrade`。禁止删除锁文件来“解锁”，禁止将数据库放在网络共享目录。

## 验证

```sh
uv run pytest -q
uv run ruff check src tests scripts
pnpm --dir frontend build
pnpm --dir frontend test
uv run python scripts/evaluate_retrieval.py
uv run python scripts/verify_task_ui.py
uv run python scripts/verify_local.py
```

自动测试集中覆盖协议续接、两级并发、跨进程锁与租约、一次性操作回执、教材修订／恢复、证据定位及必要用户约束，不设覆盖率目标。

`verify_task_ui.py` 使用真实 Chromium、本地前端构建和路由响应夹具，检查刷新后的进度恢复、各页面重复提交保护、未保存草稿保护、检索结果恢复及手机布局。它不启动 Web／worker，不访问业务数据库或外部模型；结果写入 `.verification/task-ui-*/`。

`verify_local.py` 在 `.verification/` 创建独立验收资料，启动真实 Web 和 worker，验证浏览器登录、首页快捷入口与最近记录、移动视口、练习／复习 PDF、中文与公式、配图加载及字体故障；空资料库使用独立浏览器夹具检查。生成截图、PDF 和报告后关闭服务。它不修改默认 `data/`，不调用外部模型。

GitHub Actions 配置了 Windows、macOS、Linux 的运行时预检和关键测试。本机通过不能替代另两平台实际运行；真实手机拍照和真实服务商模型质量也需要对应设备与 API Key。具体覆盖见 [验收记录](docs/validation.md)。

## 字体与许可

应用代码使用 MIT。Noto Sans CJK SC 字体和 KaTeX 字体按 OFL 随应用分发，KaTeX 代码遵循其 MIT 许可。文件、许可及下载校验信息在 `frontend/public/fonts/`；不使用外部字体 CDN，不裁剪字体。PDF 使用固定字体，工作台使用系统字体以减少移动端首次加载体积。
